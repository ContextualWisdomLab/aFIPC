## 2024-07-13 - R Backend Package without Frontend
**Learning:** 본 프로젝트(aFIPC)는 순수 R 백엔드 패키지이며, HTML/React/CSS 등의 프론트엔드 UI 컴포넌트가 존재하지 않음을 재차 확인했습니다.
**Action:** 사용자 인터페이스 개선(UX/a11y)을 적용할 대상이 없으므로, PR을 생성하지 않고 작업을 종료합니다.
## 2024-07-13 - [CLI 입력 유효성 검사 안정성 개선]
**Learning:** 순수 CLI 환경의 R 패키지에서 `readline()`으로 받은 대화형 입력을 광범위한 숫자 정규식(`grepl('^[0-9]+$')`)으로 검증한 후 `as.integer()`로 변환하면 정수 오버플로우로 인해 크래시가 발생할 수 있습니다. 이는 사용자 경험(UX)을 저해하고 잠재적인 DoS를 유발합니다.
**Action:** 지정된 CLI 프롬프트 옵션에 대해서는 항상 정확한 문자열 일치(예: `n %in% c('1', '2')`)를 사용하여 안정적인 실행을 보장해야 합니다.
