# Palette Journal

## 2024-06-24 - Pure R Backend Package

This repository (aFIPC) is a pure R backend package for Automated Fixed Item
Parameter Calibration, and it does not contain any frontend or UI components
(e.g., HTML, CSS, JavaScript, React).

## 2026-06-30 - No Frontend Surface

The aFIPC package strictly implements backend item response theory linking
methods. There is no user interface to enhance, format, or improve via Palette.
